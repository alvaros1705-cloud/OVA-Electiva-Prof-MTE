Resumen de la guía OVA

Esta guía sigue una progresión lógica: primero entiendes cómo aprenden las máquinas (ML), luego cómo se combina con la automatización (IPA), después la tecnología base de los robots de software (RPA) y, por último, practicas con herramientas reales (Power Automate y n8n).

Ruta de aprendizaje

Módulos de la guía

1Machine Learning (visión general)60 min

Machine learning es una rama de la IA en la que un sistema aprende patrones a partir de datos y mejora con la experiencia, en lugar de seguir solo reglas escritas a mano (Red Hat, s. f.-a). Jerarquía: IA ⊃ ML ⊃ Deep Learning.

Tipos de aprendizaje

  • Supervisado: datos etiquetados; clasificación y regresión (detectar spam, predecir precios).
  • No supervisado: sin etiquetas; clustering (segmentar clientes).
  • Por refuerzo: un agente aprende por recompensas (robot que aprende a caminar).

Flujo de un proyecto de ML

  1. Definir problema y métrica
  2. Recolectar datos
  3. Limpiar y preparar
  4. Dividir en entrenamiento y prueba
  5. Entrenar
  6. Evaluar
  7. Desplegar y monitorear

Métricas básicas (matriz de confusión: VP, FP, FN, VN)

MétricaFórmula
Exactitud(VP + VN) / total
PrecisiónVP / (VP + FP)
RecallVP / (VP + FN)
F12 · (precisión · recall) / (precisión + recall)

Sobreajuste: el modelo memoriza el entrenamiento y falla con datos nuevos. Subajuste: es tan simple que no aprende ni los datos de entrenamiento. Por eso se reserva un conjunto de prueba.

2Automatización Inteligente de Procesos (IPA)45 min

La IPA combina la RPA con IA (aprendizaje automático, NLP, lectura de documentos) para automatizar procesos que requerían interpretar información y decidir.

NivelQué haceDatos
TradicionalScripts o macros con reglas fijasEstructurados
RPAUn robot imita clics y teclado con reglas definidasEstructurados y digitales
IPASuma IA para interpretar, clasificar y decidirTambién no estructurados (correos, PDF, imágenes)

Ciclo de la automatización inteligente

  1. Descubrir procesos
  2. Analizar y priorizar
  3. Automatizar
  4. Medir resultados
  5. Optimizar y reentrenar

Ejemplo: factura inteligente

Llega el PDF por correo → el OCR extrae los campos → el modelo valida y calcula su confianza → si es baja, revisa una persona → RPA registra en el ERP → se confirma y se miden tiempos.

Idea clave: la IA no reemplaza el control; lo hace más eficiente (human-in-the-loop). Celonis (s. f.) señala que entre el 30 % y el 50 % de las iniciativas iniciales de RPA fracasan por elegir procesos equivocados.

3RPA: Automatización Robótica de Procesos45 min

RPA usa robots de software para realizar tareas repetitivas que antes hacían las personas (Red Hat, s. f.-b). Un bot hace lo que se le indica y no se adapta por sí solo a cambios del sistema.

Arquitectura básica

  • Studio / Designer: donde se diseña el flujo.
  • Robot (bot): ejecuta las acciones.
  • Orquestador: programa, supervisa, registra logs y custodia credenciales.
  • Colas y repositorio: trabajo pendiente y versiones.
AtendidoDesatendido
Dónde correEquipo del usuarioServidores o máquinas virtuales
Quién lo activaLa personaHorario, evento o cola

¿Qué conviene automatizar?

Sí: reglas claras, alto volumen, datos estructurados, aplicaciones estables, pocas excepciones. No (por ahora): procesos mal definidos o ineficientes (primero se rediseñan), juicio experto en cada caso, interfaz cambiante, muy bajo volumen.

Gobernanza: responsable de cada bot, control de cambios y pruebas, bóveda de credenciales, registros de ejecución y auditoría.

4Power Automate y n8n60 min

Vocabulario: flujo (workflow), trigger (evento que lo inicia), acción/nodo, conector, contenido dinámico, condición y bucle, webhook (URL que recibe una petición HTTP y dispara el flujo).

CriterioPower Automaten8n
EcosistemaIntegrado con Microsoft 365Neutral, cientos de servicios
DespliegueNube de MicrosoftAutoalojado o nube
RPA de escritorioSí (Power Automate Desktop)No es su enfoque
CódigoBajo códigoNodos JavaScript/Python

Práctica guiada: del correo a la hoja de cálculo

Cada vez que llegue un correo, guarda remitente, asunto y fecha en una hoja. Power Automate: flujo de nube automatizado → trigger «Cuando llega un correo electrónico nuevo (V3)» → «Agregar una fila a una tabla» (Excel Online). n8n: Gmail Trigger → Edit Fields (Set) → Google Sheets – Append row.

Mini-reto: agrega una condición: si el asunto contiene «urgente», envía además una notificación.

5Caso integrador: la bandeja de la Facultad30 min

La Facultad de Ingeniería recibe cada día cientos de correos de estudiantes (certificados, reingresos, fallas, consultas). Hoy dos personas los clasifican a mano, copian los datos y reenvían cada caso, con demoras y errores de digitación.

Tu misión: diseñar una solución de automatización inteligente: proceso y objetivo, rol del ML/NLP, flujo o robot, herramienta elegida, intervención humana, riesgos e indicador de éxito.

Módulo 2 · IPA

Las piezas de una solución IPA

Una solución de automatización inteligente combina varias tecnologías, cada una con un rol distinto dentro del proceso.

La minería de procesos se recomienda como paso previo para decidir qué automatizar primero (Celonis, s. f.).

RPA

Ejecuta las tareas sobre las aplicaciones. Ej.: registrar el dato en el ERP.

Machine learning

Predice o clasifica con base en datos históricos. Ej.: detectar una factura sospechosa.

NLP

Entiende texto escrito. Ej.: clasificar un correo por su intención.

OCR

Convierte imágenes o PDF en datos utilizables. Ej.: extraer número, fecha y total de una factura.

Minería de procesos

Analiza registros de eventos para ver cómo se ejecutan realmente los procesos.

Orquestación / BPM

Coordina personas, robots y sistemas. Ej.: asignar el caso dudoso a un revisor.

Módulo 3 · RPA

Ciclo de vida de un proyecto RPA

  1. 1

    Identificar procesos

    Se eligen los procesos que cumplen los criterios de un buen candidato.

  2. 2

    Documentar (PDD)

    El Process Definition Document describe paso a paso cómo se ejecuta hoy el proceso; sin él, el bot automatiza suposiciones.

  3. 3

    Desarrollar el bot

    Se construye el flujo en el Studio / Designer.

  4. 4

    Probar

    Se valida el bot con control de cambios y pruebas.

  5. 5

    Desplegar

    El robot se publica y el orquestador programa sus ejecuciones.

  6. 6

    Monitorear y mantener

    Registros de ejecución, auditoría y un responsable para cada bot.
